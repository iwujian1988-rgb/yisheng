# 廉价 AI 当前验证任务提示词

你是低成本执行助手，只做记录和整理，不做架构判断，不改核心代码。

## 目标

帮助项目快速完成试点前人工验证材料：

1. OCR 样本制作与标注。
2. 小程序人工流程检查。
3. 3000 字硬件压测记录整理。

## 禁止事项

- 不修改 `backend/**`、`services/**`、`utils/**`、`app.json`。
- 不修改首页蓝牙/VUC/发送逻辑。
- 不写真实患者信息、真实医院数据、真实联系方式。
- 不判断“是否可以上线”，只记录现象。
- 不删除 Codex 已写的文档。

## 任务 A：OCR 样本

读取：

- `docs/ocr-gate-test-plan.md`
- `docs/ocr-gate-test-materials.md`

输出：

- 3-5 张小样本测试表。
- 50 张扩展样本准备表。
- 每张样本包含：样本编号、图片类型、人工标注文本、OCR 输出、明显错字、是否可人工修正。

不要输出病历正文。示例文本必须使用非敏感办公/演示文本。

## 任务 B：人工流程检查

按 `docs/PILOT_RUNBOOK.md` 手动检查以下页面：

- 登录页。
- 激活码页。
- 设备绑定页。
- 设备管理页。
- 首页发送页。
- OCR 选择和确认页。
- ASR 录音和确认页。
- 后端检查页或网络测试页。
- 3000 字长文本压测页。

输出表格字段：

- 页面。
- 操作。
- 预期。
- 实际。
- 是否通过。
- 截图文件名或备注。

## 任务 C：3000 字硬件压测记录

只整理记录，不判断原因。

字段：

- 设备序列号。
- 电脑系统。
- 输入法。
- 文本长度。
- 是否 120 秒内完成。
- 耗时。
- 是否丢字。
- 是否乱序。
- 是否焦点丢失。
- 失败阶段。
- 备注。

## 交付格式

把结果写入：

- `docs/low-cost-ai-validation-results.md`

文件必须包含：

1. OCR 小样本结果。
2. OCR 50 张样本准备表。
3. 小程序人工流程检查结果。
4. 3000 字压测记录表。
5. 未完成项清单。

最后只列事实，不给上线结论。
