## 1. 入口

首页只有一个入口，无医疗字样：

```
┌──────────────────────────────────┐
│            首页                   │
│                                  │
│   ┌──────────┐  ┌──────────┐    │
│   │ 📋 模板   │  │ ✨ 智能创作│    │
│   └──────────┘  └──────────┘    │
│   ┌──────────┐  ┌──────────┐    │
│   │ 📷 图片   │  │ 🎤 语音   │    │
│   └──────────┘  └──────────┘    │
│                                  │
│   ┌──────────────────────────┐  │
│   │ 直接编辑                  │  │
│   └──────────────────────────┘  │
│                                  │
│   [发送到电脑]                    │
└──────────────────────────────────┘
```

## 3. 主页面（空状态）

```
┌──────────────────────────────────────┐
│  ←  智能创作                          │
├──────────────────────────────────────┤
│                                      │
│  ┌─────────────────────────────────┐ │
│  │                                 │ │
│  │  输入或粘贴内容，                │ │  ← placeholder 从后端下发
│  │  也可以点下方按钮用语音或图片     │ │     connected=false 时通用文案
│  │                                 │ │     connected=true 时医疗文案
│  │                                 │ │
│  │                                 │ │
│  └─────────────────────────────────┘ │
│                                      │
│  ┌──────┐  ┌──────┐  ┌──────────┐  │
│  │  语音  │  │  图片  │  │  AI 处理  │  │
│  └──────┘  └──────┘  └──────────┘  │
│                                      │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │
│                                      │
│  选择处理方式：                        │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │  整理文字    将内容整理为规范文本  │ │  ← 模式名称+描述都从后端下发
│  ├─────────────────────────────────┤ │     connected=false: 通用名称
│  │  润色优化    优化文字表达和用语    │ │     connected=true: 医疗名称
│  ├─────────────────────────────────┤ │
│  │  提取要点    从长文中提取关键信息  │ │
│  ├─────────────────────────────────┤ │
│  │  内容检查    检查文本的完整性      │ │
│  ├─────────────────────────────────┤ │
│  │  格式转换    按目标格式重新组织    │ │
│  └─────────────────────────────────┘ │
│                                      │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │  [可选] 我的模板  [▼ 选择模板]    │ │  ← 仅整理/检查/转换模式显示
│  │                                 │ │     模板列表从后端获取
│  │  + 导入新模板（拍照/粘贴）        │ │
│  └─────────────────────────────────┘ │
│                                      │
└──────────────────────────────────────┘
```

## 10. 数据流总结

```
前端                                后端
─────────────────────────────────────────────────
首页点击"智能创作"
  │
  ├─ 检查会员 → 非会员弹窗
  │
  └─ 进入页面
       │
       ├─ GET /api/ai/modes?connected=true/false
       │     → 获取模式列表、名称、描述、placeholder
       │     → 获取可用模板列表
       │
       ├─ 用户输入 + 选模式 + 选模板
       │
       ├─ POST /api/ai/assistant
       │     body: {
```
