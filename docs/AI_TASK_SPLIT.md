- `docs/DEVELOPMENT_STANDARDS.md`

## Codex 亲自负责

### 蓝牙核心链路

- BLE adapter 生命周期管理。
- 设备搜索、过滤、连接、断开、重连。
- 服务与特征发现。
- 写入特征封装。
- MTU 分片。
- token 队列发送。
- 发送进度、取消、暂停、失败恢复。
- 自适应速度策略。
- 真机联调与长文本稳定性分析。

原因：这是项目成败的核心，不适合交给能力较弱的 AI。

### 编码和协议层

- VUC/token 编码规则。
- 中英文、数字、标点边界处理。
- `SPD2|WIN11|` 协议适配。
- 规则测试用例。

原因：任何小错误都会导致医院电脑端乱码、丢字、卡死。

### 安全和账号架构

- 登录鉴权架构。
- token 生命周期。
- 购买用户/付费用户判断逻辑。
- 后台创建、导入、禁用付费用户的业务边界。
- 用户和硬件设备绑定逻辑。
- 用户数据加密策略。
- 管理员不可见明文的存储方案。
- AI 脱敏网关。

原因：涉及医疗数据和产品信任边界。

### AI 交互和内容生成

- DeepSeek V4 接入架构。
- AI 对话核心状态。
- 医学提示词模板。
- 病历整理、报告整理、术语校对、内容润色逻辑。
- AI 输入脱敏、输出复核、发送前确认。
- OCR/ASR 结果进入 AI 前后的处理链路。

原因：这是小程序本身的核心价值，不能交给能力较弱的 AI 拼接提示词。

### 全局工程规范

- 目录结构。
- 模块边界。
- 代码审查标准。
- 测试策略。
- 发布前检查清单。

## 低成本 AI 可以负责

### 普通页面

- 注册页 WXML/WXSS。
- 找回密码页 WXML/WXSS。
- 个人中心页。
- 会员购买页静态 UI。
- 购买记录页。
- 客服中心页。
- 意见反馈页。
- 使用教程页。
- 协议与隐私政策页。

要求：只能按既有组件和样式实现，不新增全局架构。

### 低风险业务逻辑

- 表单必填校验。
- 手机号格式校验。
- 密码强度展示。
- 倒计时按钮。
- 列表空状态。
- 页面跳转。
- toast 和 modal 文案。

要求：不得实现或修改购买状态判断、设备绑定状态判断、AI 真实请求、脱敏逻辑。

要求：不得改 `app.js`、蓝牙模块、加密模块、AI 接口模块。

### 内容整理

- FAQ 文案。
- 新手教程文案。
- 模板分类文案。
- 协议页占位内容。
- 页面静态测试文案，且不得包含真实病历或仿真病历正文。

## 需要 Codex Code Review 后才能合并

- 任何涉及 BLE 的改动。
- 任何涉及病历正文存储的改动。
- 任何涉及 AI/OCR/ASR 上传文本或图片的改动。
- 任何涉及登录、token、权限的改动。
- 任何涉及付费用户、硬件购买状态、设备绑定的改动。
- 任何涉及全局配置、路由、项目配置的改动。
- 任何涉及 AI 提示词、AI 内容生成、OCR/ASR 结果处理的改动。

## 已调通核心代码保护规则

当前 GitHub 代码中的蓝牙/VUC 发送链路已调通过。任何开发者必须遵守：

- 不允许为了“整理代码”而重写核心发送逻辑。
- 不允许改变协议 payload 语义。
- 不允许删除现有延迟、分片、取消、日志逻辑。
- 优化只能小步进行，并说明优化点。
- 修改前后必须保留可对照测试样例。
- 低成本 AI 不允许修改 `pages/home/home.js` 中蓝牙和发送相关代码，除非 Codex 已先拆分出明确模块并给出任务范围。

## 低成本 AI 任务模板

交给低成本 AI 的任务必须写清：

```text
只允许修改：
- pages/xxx/xxx.wxml
- pages/xxx/xxx.wxss
- pages/xxx/xxx.js

禁止修改：
- app.js
- app.json
- utils/ble/**
- utils/encoder/**
- services/auth/**
- services/security/**
- services/ai/**
- services/payment/**
- services/device/**

要求：
- 使用现有颜色和按钮样式。
- 不新增第三方依赖。
- 不实现真实接口，只保留函数入口；测试数据必须由 Codex 提供的 service 或任务卡明确给出。
- 完成后列出修改文件。
```
