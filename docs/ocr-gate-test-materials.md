## 1. 人工标注基准

每张样本制备后，测试人员必须将图中文字逐字录入对应区域。OCR 结果只和这里的基准文本对比。

录入规则：

- 保留原图换行位置，用 `[换行]` 标记。
- 表格用 `|` 分隔列，保留行列结构。
- 数字、标点、英文字符原样录入，不修正、不美化。
- 所有内容必须为虚构或非敏感公开文本，不得使用真实患者信息、真实病历、真实检查报告、真实处方或真实身份证明材料。

## 2. PaddleOCR / RapidOCR 对比记录

1. PaddleOCR 和 RapidOCR 分别部署为独立 worker 进程，或通过切换 `OCR_ENGINE` / `OCR_COMMAND_ARGS` 分批测试。
2. 每次只测一个引擎，避免进程互相干扰。
3. 记录编号必须与 `ocr-gate-test-plan.md` 保持一致：每张样本先记录 PaddleOCR，再记录 RapidOCR。

| 错字数 | 整数 | 原图有此字，OCR 输出了别的字 |

| 结论 | `通过` / `观察` / `失败` | 按主计划判定 |

## 3. 失败样本归因

当某条记录为“观察”或“失败”时，从下表选择归因代码填入备注。

| 代码 | 归因类别 | 表现 | 处理方向 |
|---|---|---|---|
| A | 图片质量问题 | 原图肉眼也较难辨认 | 优化拍摄引导 |
| A1 | 低光/曝光不足 | 画面偏暗、对比度低 | 产品提示改善光线 |
| A2 | 运动模糊 | 文字边缘发虚 | 产品提示稳定拍摄 |
| A3 | 倾斜/透视变形 | 文字行不水平 | 评估前置矫正 |
| A4 | 分辨率不足 | 单字像素过低 | 提示重拍或限制最小尺寸 |
| B | 引擎识别能力 | 原图清晰但 OCR 出错 | 对比引擎或调整模型 |
| B1 | 中文形近字混淆 | 如入/人、未/末 | 模型能力问题 |
| B2 | 数字/字母混淆 | 如 0/O、1/l/I、5/S | 模型能力问题 |
| B3 | 标点丢失或替换 | 中英文标点混乱 | 后处理或提示 |
| B4 | 表格结构丢失 | 行列关系丢失 | 后续表格后处理 |
| B5 | 英文单词错误 | 英文拼写被替换 | 模型能力问题 |
| C | 服务/部署问题 | 请求未正常处理 | 后端或运维修复 |
| C1 | 超时无响应 | 30 秒内无返回 | 调整 timeout 或性能 |
| C2 | 服务崩溃/5xx | 返回 500/502/503 | 修 worker |
| C3 | 返回空内容 | HTTP 200 但无文本 | 查 adapter |
| D | 安全/流程问题 | 结果未进正确流程 | 必须修复 |
| D1 | 绕过确认页 | 直接发送或直接进 AI | 立即停止测试 |
| D2 | 静默失败 | 失败但无提示 | 修前端/服务错误提示 |
| E | 幻觉/多字 | 输出原图不存在字符 | 置信度或后处理问题 |
