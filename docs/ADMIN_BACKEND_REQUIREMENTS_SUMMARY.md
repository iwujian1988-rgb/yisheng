# 管理后台需求整理

## 结论

管理后台是独立 Web 系统，不是小程序里的管理员页面。小程序页面可以保留为调试入口，但正式后台应该部署在阿里云服务器上，通过浏览器访问。

## V1.0 核心模块

1. 用户管理
   - 用户列表、详情、状态管理。
   - 禁用/解禁用户。
   - 会员开通、终止、延期。
   - 关联 Token 使用记录和操作日志。
   - 手机号等敏感字段必须脱敏展示。

2. 设备管理
   - 硬件首次绑定后注册设备。
   - 支持按 MAC、用户、状态、时间搜索。
   - 查看型号、固件版本、绑定状态、绑定用户、绑定时间。
   - 支持强制解绑，并写入操作日志。

3. 订单管理
   - 会员服务订单列表和详情。
   - 支持取消、退款等状态操作。
   - 金额字段仅后台可见，小程序侧按当前产品策略隐藏价格。

4. Token 使用记录
   - 记录 AI 调用消耗。
   - 字段包括用户、模型、agent 类型、prompt/completion/total tokens、问题摘要。
   - 不记录原始病历正文。

5. 模板库管理
   - 官方模板和用户模板管理。
   - 支持新增、编辑、上架、下架。
   - prompt 内容属于后台敏感配置，不下发给低权限用户。

6. 日志中心
   - 记录所有后台关键操作。
   - 日志不可删除。
   - 至少保留 180 天。
   - 包含操作者、IP、模块、动作、目标、结果、前后 JSON 差异。

7. 管理员账号
   - 独立后台登录，不复用小程序账号。
   - 角色：超级管理员、运营管理员、客服管理员。
   - 管理员账号增删改只允许超级管理员操作。

## 安全要求

- 后台登录 session 默认 2 小时。
- 登录连续失败 5 次锁定 30 分钟。
- 管理员密码生产环境使用 bcrypt。
- 可选 IP 白名单。
- 敏感操作必须二次确认。
- 管理员不得查看用户病历明文。

## 当前落地状态

已创建 `backend/` 后端骨架，包含：
- 管理员登录。
- 付费用户、设备、订单、Token、模板、反馈、审计日志接口。
- 小程序激活、设备绑定、加密历史、反馈、长文本测试接口。
- OCR/ASR/AI 网关占位。
- 浏览器管理后台入口：`/admin/`。
- 后台可按 `userId/openid` 给微信登录用户开通服务。
- 用户列表和审计日志已支持 CSV 导出骨架。
