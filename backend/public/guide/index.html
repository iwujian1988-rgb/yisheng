01

一、电脑输入法设置

电脑切换至“微软拼音”，并保持中文输入状态。

02

二、连接设备

  1. 将接收器插入电脑 USB 接口。
  2. 打开手机蓝牙。
  3. 在小程序首页点击“连接设备”。
  4. 选择设备，等待连接成功。
→

03

三、开始输入

  1. 在电脑打开需要输入的软件。
  2. 点击需要输入的位置，让光标处于输入状态。
  3. 在小程序输入文字并发送。

TIPS

  • 激活会员：打开“我的”，点击会员卡进入“领取已购会员”，授权微信手机号完成核验。
  • 搜索不到设备：确认接收器已插入电脑，手机蓝牙已开启后重新连接。
  • 无法输入文字：确认电脑光标在输入位置，并使用微软拼音中文状态。
  • 未识别已购会员：请使用购买时的收货手机号授权；手机号不一致时请联系客服。
