# 病历传输蓝牙Demo

## 功能说明

这是一个用于验证ESP32硬件蓝牙通信的微信小程序Demo。

### 主要功能

1. **蓝牙连接** - 搜索并连接ESP32硬件设备
2. **文本输入** - 支持输入中文、英文、数字、标点符号
3. **VUC转换** - 自动将中文转换为微软拼音V模式格式
4. **数据发送** - 通过蓝牙发送转换后的数据给硬件

## 使用步骤

### 1. 导入项目

1. 打开微信开发者工具
2. 导入项目，选择 `D:\product\bingli\ble-demo` 目录
3. 选择「测试号」或填写自己的AppID

### 2. 电脑端设置

确保目标电脑已开启微软拼音V模式：
- 设置 → 时间和语言 → 语言 → 中文（简体）→ 选项
- 微软拼音 → 选项 → 高级 → 启用V模式输入

### 3. 硬件准备

- ESP32设备已烧录固件
- 设备蓝牙名称包含"舒克"或"BLE"
- 设备已连接到电脑USB口

### 4. 测试流程

1. 点击「搜索设备」连接蓝牙
2. 在输入框输入文本，如："舒克，硬件烧录好了；"
3. 查看转换结果是否正确
4. 点击「发送到硬件」
5. 观察电脑端光标位置是否正确输出文本

## 蓝牙协议格式

```
SPD2|WIN11|vuc8212 vuc514b vucff0c vuc786c vuc4ef6 ...
│    │     │
│    │     └─ 用空格分隔的vuc指令
│    └─ 兼容模式标识
└─ 速度档位 (SPD1/SPD2/SPD3)
```

## UUID配置

```
服务UUID:     6E400001-B5A3-F393-E0A9-E50E24DCCA9E
写特征UUID:   6E400002-B5A3-F393-E0A9-E50E24DCCA9E (手机→硬件)
通知特征UUID: 6E400003-B5A3-F393-E0A9-E50E24DCCA9E (硬件→手机)
```

## 注意事项

1. 手机需开启蓝牙权限
2. 设备名称需包含"舒克"或"BLE"才能被识别
3. 长文本会分片发送，每片20字节
4. 发送过程中请保持蓝牙连接稳定
